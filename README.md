# Nexum [In Progress]
Chat platform that you never asked, but always wanted.

# Project Setup [For Dev]

## Prerequisites
- Node.js (v24+ recommended)

## Setup & Run

**Frontend (Quasar):**
```bash
cd frontend
npm install
npm run dev
```

**Backend (AdonisJS):**
```bash
cd backend
npm install
npm run dev
```

## Build

**Frontend:**
```bash
cd frontend
npm run build
```

**Backend:**
```bash
cd backend
npm run build
```
